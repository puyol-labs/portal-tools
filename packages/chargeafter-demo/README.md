# Demo data: @puyol-labs/chargeafter-demo

A self-contained fictional ChargeAfter fixture package for agent and policy demonstrations. It makes no HTTP calls and reads no secrets.

Install it in a blueprint as `@puyol-labs/chargeafter-demo`. The package has no infrastructure grants. Grant the required `chargeafter.com/...` capabilities to `main` to control access to fixture operations.

See [the package documentation](docs/readme.md) for the operations, fictional coverage, and capability fields.
